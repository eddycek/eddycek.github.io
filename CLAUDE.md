# vaclaveder.cz

Personal site of Václav "eddycek" Eder. Astro (static), vanilla Canvas animations, no runtime deps.

## Content
- All copy lives in `src/content/cs.ts` and `src/content/en.ts` (same shape, `types.ts`). Keep both in sync.
- `src/content/slayer.ts` holds the full poem (verbatim, never edit wording).
- Contact details and social links: `src/content/contact.ts`.
- Style rules for copy: no em dash; use semicolons instead of colons in prose; "Dark Factory" capitalised; "kontent" instead of "obsah"; "independent" for artists; "MacBook" not "notebook". Czech copy uses ty (tykání, "Napiš mi"), never vy. Use Eddy's anglicisms (business, shipovat, mindset, game changer, scale…). "Music" not "hudba", "Cyber security" not "Security". Hero shows "Vaclav" without diacritics; meta and JSON-LD keep "Václav". Never mention moving to Prague. Hero: "Vaclav" with light CRT scanlines (ink / 62% ink) and a subtle cyan/orange RGB split; "Eder" solid light, indented. Nickname glitches gently (data-glitch="name"). Never put game or film artwork or a recognisable character likeness on the site.

## Workflow for every change
1. `npm run dev` for live work (http://localhost:4321).
2. `npm run test:responsive`: builds, then runs Playwright on iPhone SE, iPhone 15 Pro, Pixel 7, iPad Mini,
   iPad Pro 11 landscape and Galaxy Tab S4. Checks: no console errors, no horizontal overflow, tap targets ≥ 24px,
   poem dialog opens/fits/closes, non-Czech browsers redirect to /en/.
3. `npm run shots`: section-by-section screenshots per device into `shots/` (gitignored); look at them after layout changes.
   Needs a running preview on :4322 (`npx astro preview --port 4322`) or pass a base URL.
4. `npm run shots:iphone`: WebKit iPhone timeline screenshots of the hero with animations on (0.3 s, 2.5 s, 8 s). Use it for Safari-only bugs; e.g. `background-clip: text` must also be set on the decode `.sd-c` spans.
5. CI (`.github/workflows/ci.yml`) runs build, link check and the responsive suite on every PR; deploy runs on push to `master`.

Icons, favicon, manifest and OG cards (`public/og.png`, `public/og-en.png`) are generated by `npm run assets`; rerun after changing the name, claim or colours.

Hero portrait: `public/portrait/eddy-{560,960}.webp`, a person cutout drawn by `src/scripts/signal/portrait.ts` as a video feed (acquire sweep, pointer interference, glitch on hero clicks, static on FAILSAFE). To replace the photo: `swift scripts/segment.swift photo.heic cut.png` (macOS Vision) then `node scripts/portrait.mjs cut.png`. If the new photo frames the face differently, adjust `FACE` in portrait.ts.

First-time setup: `npm ci && npx playwright install chromium webkit`.
