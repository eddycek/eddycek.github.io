# vaclaveder.cz v2: "Signál a šum"

## Goals

1. **Working site again.** No runtime dependency on third-party CDNs (root cause of the current breakage: `code.getmdl.io` returns 403). Everything is built and self-hosted on GitHub Pages.
2. **Visually striking.** A live, moving telemetry aesthetic: oscilloscope traces, spectrogram, text that resolves out of noise. Motion is the identity, not decoration.
3. **Eddy's voice.** Direct, confident, a bit of irony, no corporate fluff. Czech first, English at `/en/`.
4. **Career + personal life.** CTO at Keboola; SRE and security background; formal education in electrical engineering (one line, nothing more). Personal: FPV drones (FPVPIDlab) and poetry.
5. **Privacy.** Location only "Praha". E-mail and phone shown. No private repos, no internal Keboola details.
6. **Quality bar.** Lighthouse ≥ 95 in all categories, WCAG AA contrast in both themes, `prefers-reduced-motion` respected, 60 fps on a laptop, animations pause off-screen, JS < 40 kB gzip.

## Non-goals

- Blog/CMS (the 2009–2013 blog stays as an external archive link).
- Analytics with cookies.

## Design tokens

- Dark-first. Graphite `#0B0E12` ground, ink `#E8EBEE`, signal orange `#FF7A2F`, cool trace cyan `#5CC8D6` as the secondary trace only, noise grey `#3A4350`. Light theme mirrors it on `#ECEEF0`.
- Type: Bricolage Grotesque (display, very large, tight), IBM Plex Sans (body), JetBrains Mono (OSD labels, data, numbers).
- One accent (orange). Cyan is used only inside canvases as a second channel.

### Animation API (contract)

```ts
// each returns a disposer; all read colors from CSS custom properties on the canvas element
mountScope(canvas: HTMLCanvasElement): () => void      // hero oscilloscope
mountSpectrum(canvas: HTMLCanvasElement): () => void   // FFT waterfall for #dilna
mountTrace(canvas: HTMLCanvasElement, points: {year:number, level:number, label:string}[]): () => void // career flight log
decodeText(root: HTMLElement): () => void              // glyph-noise → text for [data-decode]
```

Rules: DPR capped at 2, pause via IntersectionObserver + `visibilitychange`, static final frame under `prefers-reduced-motion`, re-read colors on theme change, no allocations per frame in hot loops.

### Content schema

`src/content/types.ts` defines `SiteContent` (hero, work, journey[], workshop[], poetry, contact, meta). Both languages must satisfy it.

## Steps

1. Scaffold Astro, tokens, base layout, fonts. Commit.
2. Spawn "signal" and "copy" agents in parallel; meanwhile build components and CI.
3. Integrate modules and content; `npm run build` green.
4. Screenshots (desktop + mobile, both themes) → "Eder" review → fixes.
5. Lighthouse run, link check.
6. PR `redesign-v2` → `master`. On merge: switch Pages to `build_type=workflow` (one `gh api` call) so the Actions deploy goes live.
